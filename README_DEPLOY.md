# PEA Budget — คู่มือติดตั้งสำหรับสำนักงานใหม่

แอปคุมงบก่อสร้างจากรายงาน **ZPSR018** — อ่านไฟล์ PDF → คุมยอดคงเหลือรายหมวด → เปิดใบตัดงบเป็น PDF ส่งบัญชี

แอปแยก 2 ฝั่ง:

| ฝั่ง | คืออะไร | ใครดูแล |
|---|---|---|
| **หน้าเว็บ** | โค้ดใน repo นี้ (เปิดผ่าน GitHub Pages) | ส่วนกลาง — ใช้ตัวเดียวกันทุกสำนักงาน |
| **ฐานข้อมูล** | Google Apps Script + Google Sheet | **สำนักงานตัวเอง** — บัญชี Google ของสำนักงาน |

ข้อมูลงบของแต่ละสำนักงาน**อยู่ในไดรฟ์ของตัวเอง ไม่ปนกัน** สำนักงานใหม่ทำตามคู่มือนี้จบได้เองโดยไม่ต้องแก้โค้ดหน้าเว็บ

**เวลาที่ใช้:** ประมาณ 15 นาที ทำครั้งเดียว

---

## สิ่งที่ต้องเตรียม

- บัญชี Google ของสำนักงาน (แนะนำให้เป็นบัญชีกลาง ไม่ใช่บัญชีส่วนตัวของใครคนหนึ่ง — คนย้ายแล้วข้อมูลจะไม่หายไปด้วย)
- ไฟล์ในโฟลเดอร์นี้: `Code.gs`, `logic.gs`

---

## ขั้นที่ 1 — สร้างโปรเจก Apps Script

1. เข้า https://script.google.com → **New project** → ตั้งชื่อโปรเจก เช่น `PEA Budget กฟส.<ชื่อสำนักงาน>`
2. สร้างไฟล์ 2 ไฟล์แล้ววางโค้ด:
   - `Code.gs` — ลบโค้ดตัวอย่างทิ้ง แล้ววางเนื้อจาก `Code.gs` ใน repo
   - `logic.gs` — กด **＋ > Script** ตั้งชื่อ `logic` แล้ววางเนื้อจาก `logic.gs`

## ขั้นที่ 2 — ตั้งชื่อสำนักงาน (แก้ 2 บรรทัด)

บนหัวไฟล์ `Code.gs` มี 2 บรรทัดนี้ แก้ให้เป็นของสำนักงานตัวเอง:

```js
var OFFICE = 'กฟส.คำชะอี';   // ชื่อสำนักงาน — ขึ้นหัวแอป + ตั้งชื่อสเปรดชีตตอน setup()
var FILE_PREFIX = 'KCE';      // ตัวนำหน้ารหัสแฟ้ม เช่น KCE01, KCE02
```

ตัวอย่าง กฟส.หนองสูง:

```js
var OFFICE = 'กฟส.หนองสูง';
var FILE_PREFIX = 'NSN';
```

> `FILE_PREFIX` ใช้ตั้งรหัสแฟ้มที่โชว์บนหัวใบตัดงบ **เลือกแล้วอย่าเปลี่ยนทีหลัง** เพราะรหัสถูกเขียนลงชีตไปแล้ว

## ขั้นที่ 3 — สร้างฐานข้อมูล + template (กดปุ่มเดียว)

1. เลือกฟังก์ชัน **`setup`** จาก dropdown ด้านบน → กด **Run**
2. ครั้งแรกจะขออนุญาต scope (Spreadsheet + Drive) → กดอนุญาต
3. ดู **Execution log** จะได้ผลตรวจแบบนี้:

```

✅ ตั้งชื่อสำนักงาน — กฟส.หนองสูง
✅ ตั้ง prefix รหัสแฟ้ม — NSN
✅ มี SHEET_ID — 1N1ZJP...
✅ เปิดสเปรดชีตได้ — https://docs.google.com/spreadsheets/d/...
✅ มีครบ 4 แท็บ
✅ ข้อมูลในชีต — งบ 0 ก้อน · ใบตัด 0 ใบ
✅ มี TEMPLATE_DOC_ID — 1xZ2iH...
✅ template เป็น Google Doc เปิดได้
🎉 ติดตั้งครบ พร้อม Deploy เป็น Web app ได้เลย
```

`setup()` สร้างสเปรดชีต **และก๊อป template ใบตัดงบลงไดรฟ์ให้เอง** ไม่ต้องอัปโหลดหรือแปลงไฟล์เอง

> **ถ้ามีบรรทัด ❌** ให้แก้ตามที่บอกแล้วรันฟังก์ชัน **`selfTest`** ซ้ำจนขึ้น 🎉 ครบ
> (`selfTest` รันซ้ำได้ตลอด ไม่แก้ไขข้อมูลอะไร ใช้ตรวจสุขภาพระบบภายหลังก็ได้)

1. ขอไฟล์ `ใบตัดงบ_template_v_final2.docx` จากผู้พัฒนา แล้วอัปขึ้น Drive ของสำนักงาน

   ⚠️ ห้ามข้าม — ถ้าปล่อยเป็น `.docx` เวลาออก PDF จะขึ้น *"ไม่สามารถเข้าถึงเอกสารได้"* เพราะโค้ดเปิดได้เฉพาะ Google Doc เนทีฟ

## ขั้นที่ 4 — Deploy

1. **Deploy > New deployment > ⚙ (เฟือง) > Web app**
2. ตั้งค่า:
   - Execute as: **Me**
   - Who has access: **Anyone**
3. **Deploy** → ก๊อป **Web app URL** (ลงท้าย `/exec`) เก็บไว้

> ทดสอบเร็วๆ: เอา URL เปิดในเบราว์เซอร์ตรงๆ ต้องได้ JSON หน้าตาแบบ
> `{"ok":true,"service":"ใบตัดงบ กฟส.<ชื่อสำนักงาน>",...}` — ถ้าชื่อสำนักงานถูก แปลว่าขั้น 1-2 ผ่าน

## ขั้นที่ 5 — เชื่อมหน้าเว็บ

1. เปิดแอป: https://potcharapea.github.io/KceBudget/
2. ครั้งแรกจะเจอหน้า **"เชื่อมต่อฐานข้อมูลของสำนักงาน"** → วาง URL `/exec` → กดบันทึก
3. เสร็จ — หัวแอปจะขึ้นชื่อสำนักงานที่ตั้งไว้ในขั้นที่ 2

URL จะถูกจำไว้ในเครื่อง (`localStorage`) ต่อ 1 เบราว์เซอร์ **เครื่องอื่น/คนอื่นในสำนักงานต้องกรอกครั้งแรกเหมือนกัน** — ส่ง URL ให้กันได้เลย

## ขั้นที่ 6 — ใส่ข้อมูลตั้งต้น

เปิดสเปรดชีต แท็บ **ตั้งค่า** (A = ประเภท, B = ค่า) เพิ่มแถวได้เรื่อยๆ:

| ประเภท | ตัวอย่างค่า |
|---|---|
| `พขร.` | ชื่อพนักงานขับรถ |
| `ผู้เบิก` | ชื่อผู้เบิก |
| `บริษัท` | ชื่อบริษัทผู้รับเหมา |
| `ทะเบียนรถ` | กข 1234 มุกดาหาร |

ทั้ง 4 ประเภทเพิ่มจากในแอปได้เหมือนกัน (ปุ่ม ＋ ข้าง dropdown) ไม่จำเป็นต้องเปิดชีต

## ⚠️ เวลาแก้โค้ด GAS แล้วต้อง redeploy

- แก้ `Code.gs`/`logic.gs` แล้ว **ต้อง Deploy > Manage deployments > (ดินสอ) > Version: New version > Deploy**
- **URL `/exec` เดิมใช้ต่อได้** ถ้า redeploy ทับ deployment เดิม (ไม่ต้องกรอก URL ใหม่ในแอป)
- ถ้ากด **New deployment** = ได้ URL ใหม่ ต้องไปกรอกในแอปใหม่ทุกเครื่อง
- หน้าเว็บส่วนกลางอัปเดตทันทีที่ push แต่ GAS ต้อง redeploy เอง — **ถ้าเวอร์ชันไม่ตรงกันอาจมีฟีเจอร์ที่ยังใช้ไม่ได้**

## แก้ปัญหาที่เจอบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| หน้าแรกขึ้น "เชื่อมต่อไม่สำเร็จ" | URL ผิด หรือยังไม่ได้ Deploy — กดปุ่ม "ตั้งค่าที่อยู่เซิร์ฟเวอร์" แล้วกรอกใหม่ |
| ออก PDF แล้วขึ้น "ไม่สามารถเข้าถึงเอกสารได้" | template ยังเป็น `.docx` ไม่ได้แปลงเป็น Google Doc (ขั้นที่ 3 — รัน `selfTest` ดู) |
| ออก PDF แล้วขึ้น "ยังไม่ได้ตั้งค่า TEMPLATE_DOC_ID" | ยังไม่ได้ใส่ Script Property (ขั้นที่ 3 — รัน `selfTest` ดู) |
| อ่านไฟล์ ZPSR018 แล้วขึ้น "อ่าน WBS ไม่ได้" | รูปแบบ WBS ใหม่ที่ parser ยังไม่รู้จัก — กรอกหมายเลขงานเองไปก่อนได้ แล้วแจ้งผู้พัฒนา |
| รหัสแฟ้มขึ้นผิด prefix | เปลี่ยน `FILE_PREFIX` หลังมีข้อมูลแล้ว — แถวเก่าจะยังเป็นรหัสเดิม |
