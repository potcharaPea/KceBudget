# PEA Budget — แอปคุมงบก่อสร้าง กฟภ.

> เปิดแอป: **https://potcharapea.github.io/KceBudget/**

แอปคุมงบก่อสร้างจากรายงาน **ZPSR018** — อ่านไฟล์ PDF → คุมยอดคงเหลือรายหมวด → เปิดใบตัดงบ → พิมพ์/บันทึก PDF ส่งบัญชี

ทุกสำนักงานใช้หน้าเว็บและฐานข้อมูล (Supabase) ตัวเดียวกัน **ข้อมูลแยกตามสำนักงาน ไม่ปนกัน**

---

## เริ่มใช้งาน (สำนักงานใหม่ ไม่ต้องติดตั้งอะไร)

1. เปิดแอป → ครั้งแรกจะเจอหน้า **"เลือกสำนักงาน"**
2. มีชื่อสำนักงานตัวเองแล้ว → กดเลือก · ยังไม่มี → กรอกในกล่อง **"เพิ่มการไฟฟ้าใหม่"**
   - **ชื่อสำนักงาน** เช่น `กฟส.มุกดาหาร` — ขึ้นหัวแอปและหัวใบตัดงบ
   - **ตัวย่อรหัสแฟ้ม** เช่น `MDH` (A-Z/0-9 ยาว 2-5 ตัว **ห้ามซ้ำสำนักงานอื่น**) — ใช้ตั้งรหัสแฟ้ม MDH01, MDH02
3. เสร็จ — ระบบจำสำนักงานไว้ในเครื่องนั้น **เครื่องอื่น/คนอื่นเปิดครั้งแรกต้องกดเลือกเหมือนกัน**

เปลี่ยนสำนักงาน/ตัวย่อรหัสแฟ้มทีหลังได้ที่เมนู **⚙ เลือก/เพิ่มสำนักงาน** ใน sidebar
(เปลี่ยนตัวย่อแล้วรหัสแฟ้มเดิมจะถูกเขียนใหม่ทั้งหมดโดยคงเลขรัน — ใบตัดที่พิมพ์ไปแล้วยังเป็นรหัสเก่า)

รายชื่อ พขร. / ผู้เบิก / บริษัท / ทะเบียนรถ เพิ่มจากในแอปได้เลย (ปุ่ม ＋ ข้าง dropdown)

## ออกใบตัดงบ PDF

แฟ้มงาน → **สรุป/งวด** → **PDF** → หน้าต่างพิมพ์เปิดขึ้น → เลือกเครื่องพิมพ์ **"บันทึกเป็น PDF"**
- ติ๊ก **หัวกระดาษและท้ายกระดาษ ออก** (ไม่งั้นจะมีวันที่/URL ติดบนใบ)
- มือถือ: กดปุ่ม **"พิมพ์ / บันทึก PDF"** ที่เด้งขึ้นมา แล้วแชร์/บันทึกจากหน้าตัวอย่างก่อนพิมพ์

## แก้ปัญหาที่เจอบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| เปิดแอปแล้วเป็นเวอร์ชันเก่า | รีโหลด 2-3 ครั้ง หรือปิดแอป (PWA) แล้วเปิดใหม่ |
| เห็นข้อมูลผิดสำนักงาน | ⚙ เลือก/เพิ่มสำนักงาน → กดสำนักงานที่ถูก |
| เพิ่มสำนักงานไม่ได้ "ตัวย่อรหัสแฟ้มนี้มีสำนักงานอื่นใช้แล้ว" | เลือกตัวย่ออื่น |
| อ่านไฟล์ ZPSR018 แล้วขึ้น "อ่าน WBS ไม่ได้" | รูปแบบ WBS ใหม่ที่ parser ยังไม่รู้จัก — กรอกหมายเลขงานเองไปก่อนได้ แล้วแจ้งผู้พัฒนา |

---

## สำหรับผู้พัฒนา

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` / `app.js` | หน้าจอทั้งหมด |
| `api.js` | คุยกับ Supabase — `callApi(action, data)` ทุก action ของแอปอยู่ที่นี่ |
| `slip.js` | วาดใบตัดงบ (SVG A4 ตามพิกัดของฟอร์ม Google Doc เดิม) แล้วสั่งพิมพ์ — **แก้หน้าตาฟอร์มที่ไฟล์นี้** |
| `parser.js` | อ่าน ZPSR018 (pdf.js ใน `vendor/`) |
| `config.js` | URL + publishable key ของ Supabase |
| `supabase/schema.sql` | ตาราง / view `budgets_v` / ฟังก์ชัน `create_slip` / RLS — วางใน SQL Editor แล้ว Run (รันซ้ำได้) |

```
node _serve.mjs                   # เปิด http://localhost:8123 (ES module ต้องผ่าน http)
node test_parser.mjs              # parser ZPSR018 — WBS แบบ C / I / P + เลขกิจกรรม
node test_alloc.mjs               # ยอดจัดสรรรวมทั้ง WBS
node supabase/check_schema.mjs    # schema: กันเบิกเกิน / เพดานทั้งงาน / กันกดซ้ำ / cascade
node supabase/check_api.mjs       # api.js ทุก action กับ Supabase จริง (ใช้สำนักงานทดสอบแล้วลบเอง)
```

- **ความปลอดภัย:** ไม่มีระบบล็อกอิน — RLS เปิดให้ anon อ่าน/เขียนได้ (เลือกไว้แล้ว) รหัสผ่านตอนลบเป็นด่านบนหน้าจอเท่านั้น
  ถ้าจะผูกสิทธิ์กับสำนักงาน แก้ policy ท้าย `schema.sql` ไม่ต้องแก้ตาราง · **ห้ามใส่ secret / service_role key ในโค้ด**
- ย้ายข้อมูลจากระบบ GAS + Google Sheet เดิม: `supabase/migrate_from_sheet.cjs` (วิธีใช้อยู่หัวไฟล์)
